🐞 BugBank - Praticando Automação de Testes com Cypress

Este projeto é uma aplicação e-commerce fictícia, repleta de falhas propositais, desenvolvida para fins educacionais. Seu objetivo é permitir que profissionais e estudantes pratiquem o planejamento e a automação de testes em um ambiente que simula cenários reais.​

🚀 Funcionalidades

> Login de usuários
> Cadastro de contas
> Compra de produtos
> Visualização de Carrinho
> Pagamentos de boletos e Cartão
> Visualização de Compra

Nota: A aplicação não utiliza um banco de dados; todas as informações são armazenadas em memória local.​

🧪 Tecnologias Utilizadas

> Cypress 
> JavaScript
> Node.js​
> GitHub
